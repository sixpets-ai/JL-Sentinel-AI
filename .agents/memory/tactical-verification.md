---
name: Tactical layout verification
description: Verify authenticated mobile layouts without repeating paid AI or IBM operations.
---

For SANTI map/graph views, check mobile layouts with an authenticated report loaded, not only the anonymous page or desktop workflow.

**Why:** A successful desktop generation/persistence check missed overflow in the graph and authenticated report. Anonymous previews do not exercise all report and account controls.

**How to apply:** Use an isolated, test-owned synthetic report fixture for layout-only retests and remove it afterward. Do not repeat Gemini generation or IBM evaluation just to check responsive sizing.
